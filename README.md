# Gym Management System (Spor Salonu Yönetim Sistemi)
Bu proje, ASP.NET Core MVC kullanılarak geliştirilmiş bir Spor Salonu Yönetim ve Randevu Sistemi'dir.

## Özellikler:
- Üye ve Antrenör Yönetimi
- Randevu Sistemi
- Gemini AI Destekli Kişiselleştirilmiş Antrenman Planı
- Admin Paneli ve Rol Tabanlı Yetkilendirme

## Teknolojiler:
- ASP.NET Core MVC
- Entity Framework Core (SQL Server)
- Gemini AI API
- Bootstrap
